# Scouting

Web app per gestire i giocatori visionati: schede con foto, osservazioni per partita, giudizio finale, commenti dello staff, ricerca rapida ed esportazione PDF.

- **Multi-utente** con Supabase: lo scout inserisce, presidente/direttore/allenatore consultano e commentano.
- **Funziona offline**: i dati sono salvati anche sul dispositivo e si sincronizzano appena torna la rete.
- Installabile sul telefono (Aggiungi a schermata Home).

Configurazione: vedi [SETUP.md](SETUP.md).
