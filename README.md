# Scouting

Web app per gestire i giocatori visionati: schede con foto, osservazioni per partita, giudizio finale, ricerca rapida ed esportazione PDF.

- Funziona offline ed è installabile sul telefono (Aggiungi a schermata Home).
- I dati restano sul dispositivo (IndexedDB).
- Per passare i dati da un dispositivo all'altro: **Backup → Esporta**, poi **Importa** sull'altro dispositivo. L'import unisce i dati e tiene la versione più recente di ogni scheda.
